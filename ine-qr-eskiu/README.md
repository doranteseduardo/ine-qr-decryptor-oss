# ine-qr-eskiu — INE QR decoder pipeline in Eskiu

A sixth implementation of the decoder, written in [Eskiu](https://eskiu-lang.org)
(a systems language that compiles to native code via LLVM).

The crypto + output pipeline (AES-256-CBC + RSA-8192 → 18 biographical fields +
WebP photo) is pure Eskiu — a direct port of the reference pipeline, producing
bit-identical output. Its value is as an **independent transcription**: two ports
written from the same specification that agree byte-for-byte are unlikely to
share a transcription error. QR extraction reuses **ine-qr-c's** portable reader
(`stb_image` + `zxing-cpp`), so the image path builds on Linux as well as macOS —
no CoreGraphics.

```
decoder/
  pipeline.esk     # the three decode stages
  crypto.esk       # AES + RSA rounds, key derivation
  output.esk       # decrypted blob → 18 fields + WebP
  types.esk        # shared types
  extern.esk       # C declarations (libc, OpenSSL, zxing shim)
  qr_extract.c     # thin C adapter to ine-qr-c's qr_extract
tests/
  pipeline_test.esk  # parity check against output/qr_*.bin
```

## Build

Requires:
- **eskiuc** — the Eskiu compiler. Install it from the public
  [Eskiu releases](https://github.com/doranteseduardo/eskiu/releases)
  (grab the prebuilt asset for your platform and put `eskiuc` on your `PATH`),
  or build it from source: `git clone https://github.com/doranteseduardo/eskiu
  && cd eskiu && cmake -S . -B build && cmake --build build` (then use
  `make ESKIUC=/path/to/eskiu/build/eskiuc`). On Linux,
  `vendor/fetch-eskiuc.sh` downloads the release tarball for you (via `gh` if
  present, else `curl`).
- **OpenSSL** and **zxing-cpp** (macOS: `brew install openssl@3 zxing-cpp`;
  Linux: build zxing-cpp from source — see `.github/workflows/ci.yml` for the
  exact recipe).
- A C/C++ toolchain.

```bash
make                              # build + run the parity test
make ESKIUC=/path/to/eskiuc       # if eskiuc isn't on PATH
make objects                      # compile the QR-extraction adapter
make safe                         # rebuild with --safe (bounds-check every index)
```

## Parity test

`make test` compiles `tests/pipeline_test.esk` and runs it **from the project
root**, where it reads the pre-extracted payloads `output/qr_izquierdo.bin` and
`output/qr_derecho.bin` (858 bytes each), runs the full crypto pipeline, and
decodes the result to JSON + WebP. Those payloads are generated by any of the
other paths; they are git-ignored and never committed.

The test needs only `-lcrypto` — it feeds the pipeline pre-extracted payloads,
so no QR reader is involved.

## Standard-library features it exercises

`<mem>` for the buffer ownership model (the caller allocates output buffers;
stages document which pointer must be freed) and Eskiu's `Result<T,E>` for error
propagation across the three stages.
